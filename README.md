# Система сбора и обработки данных датчиков

Учебный проект на базе Arduino, Node-RED и SQLite. Проект предназначен для обработки показаний датчиков, выявления событий и сохранения результатов в реляционной базе данных.

## О проекте

Система принимает данные датчиков в текстовом формате, обрабатывает их с помощью Node-RED и загружает в базу данных SQLite.

Основные возможности:
- получение показаний датчиков из Serial Monitor симулятора Wokwi;
- обработка строк с данными и событиями;
- формирование SQL-запросов автоматически;
- создание структуры базы данных и загрузка результатов;
- разделение показаний датчиков и событий в отдельные таблицы.

## Используемые технологии

- **Arduino / Wokwi** — моделирование устройства и получение данных датчиков;
- **Node.js** — среда выполнения Node-RED;
- **Node-RED** — визуальная автоматизация обработки данных;
- **SQLite** — хранение данных в реляционной базе;
- **SQL** — описание структуры базы данных и добавление записей.

## Структура проекта

```text
prikhodko_kurs/
├── data/
│   └── log.txt             # Входные данные датчиков
├── db/
│   └── schema.sql          # SQL-схема базы данных
├── docs/                   # Документация проекта
├── nodered/
│   └── flows.json          # Поток Node-RED
├── .gitignore
└── start-nodered.bat       # Запуск Node-RED
```

Локальная база данных `variant.db` и генерируемый файл `load.sql` создаются в процессе работы и не хранятся в репозитории.

## Требования

Для запуска необходимы:
- Windows;
- Node.js;
- Node-RED;
- SQLite CLI (`sqlite3.exe`);
- исходный проект, скачанный или клонированный из GitHub.

## Установка

### 1. Клонирование репозитория

Откройте CMD и выполните:

```cmd
git clone https://github.com/kobak228/prikhodko_kurs.git
cd prikhodko_kurs
```

### 2. Подготовка окружения

Файл `start-nodered.bat` рассчитан на расположение Node.js и Node-RED в каталогах:

```text
%USERPROFILE%\tools\node
%USERPROFILE%\tools\nodered
```

Если у вас используются другие пути, измените соответствующие переменные в `start-nodered.bat`.

Убедитесь, что Node-RED установлен и доступен по пути, указанному в скрипте.

Также установите SQLite CLI и проверьте путь к `sqlite3.exe` в узле `exec` потока Node-RED. Если путь отличается от настроенного в проекте, замените его на свой.

### 3. Подготовка базы данных

Убедитесь, что каталог `db` существует. SQL-схема находится в файле `db/schema.sql`.

При необходимости создайте каталог вручную и настройте пути к файлам базы данных в потоке Node-RED.

### 4. Подготовка входных данных

Данные помещаются в файл `data/log.txt`. Пример формата:

```text
DATA n=1 s1=20.0 s2=65.0 s3=0
DATA n=2 s1=22.0 s2=63.0 s3=0
DATA n=3 s1=35.0 s2=60.0 s3=0
DATA n=4 s1=45.0 s2=58.0 s3=1
EVENT n=4 type=THRESHOLD
```

Чтобы получить реальные данные, запустите скетч Arduino в Wokwi, откройте Serial Monitor и перенесите вывод в `data/log.txt`.

## Запуск

1. Откройте каталог проекта.
2. Запустите `start-nodered.bat`.
3. Дождитесь запуска Node-RED.
4. Откройте в браузере [http://localhost:1880](http://localhost:1880).
5. Проверьте, что поток из `nodered/flows.json` загружен.
6. Нажмите **Deploy**, если поток был изменён.
7. Запустите узел чтения и обработки данных согласно настройкам потока.
8. Проверьте выполнение операций и содержимое базы данных.

## Обработка данных

Поток Node-RED выполняет следующие этапы:

1. Чтение входного файла `data/log.txt`.
2. Разбор строк с показаниями датчиков и событиями.
3. Формирование SQL-команд.
4. Сохранение команд в `db/load.sql`.
5. Выполнение SQL-команд с помощью SQLite CLI.

Схема базы данных задаётся в `db/schema.sql`. Показания датчиков и события хранятся в отдельных таблицах.

**Важно:** текущая логика загрузки очищает таблицы перед повторным импортом. Поэтому при повторной обработке файла база формируется заново на основе его текущего содержимого, а не дополняется только новыми строками.

## Возможные проблемы

- **Node-RED не запускается:** проверьте пути к Node.js и Node-RED в `start-nodered.bat`.
- **SQLite не запускается:** проверьте путь к `sqlite3.exe` в узле `exec`.
- **Данные не загружаются:** проверьте формат строк в `data/log.txt`, наличие `db/schema.sql` и правильность путей.
- **В браузере не открывается редактор:** убедитесь, что Node-RED запущен и порт `1880` не занят другим процессом.
